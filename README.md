# Kyle Nel — Portfolio

React 19 + TypeScript + Vite + Tailwind v4 + Motion.

```bash
npm install
npm run dev
```

## Swap the placeholder face

Replace `public/avatar-placeholder.svg` with a square photo (600px+) and update `FACE_SRC` in `src/components/Avatar.tsx`. The hero avatar and the nav hover card both read from it.

## Contact form

Copy `.env.example` to `.env` and fill in the EmailJS keys.
